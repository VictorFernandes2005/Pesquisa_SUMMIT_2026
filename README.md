# Pesquisa_SUMMIT_2026

## How to Use:

> * Download the spreadsheet and Notebook files
> * Open the Notebook in your preferred platform, that supports ``.ipynb``. Ex.: [Google Colab](https://developers.google.com/colab)
> * Inside the Notebook, load the File ``litDigestFull.xlsx``
> * Select to run all from the beginning
